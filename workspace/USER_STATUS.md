# USER_STATUS.md

_Estado global do Lauro Vitor, compartilhado entre todos os canais da Luna._

Pensa nisso como a **ficha viva do jogador principal**: humor, clima, energia, sinais afetivos e contexto emocional recente.

## Finalidade

Este arquivo existe para a Luna:
- manter uma leitura **global** do estado do Lauro;
- ajustar tom, carinho, objetividade, delicadeza e intensidade emocional;
- evitar interpretações erradas por silêncio em um canal quando há contato em outro;
- preservar continuidade emocional entre WhatsApp, Telegram, Slack, dashboard chat e canais futuros.

## Regras de uso

- Este arquivo é a **fonte principal** do estado emocional/global do Lauro.
- Não manter versões separadas por canal.
- Atividade em qualquer canal conta como atividade global.
- Se o Lauro disser “falei isso em outro canal”, a Luna deve verificar esse outro canal/sessão quando possível.
- Este arquivo serve para **tom e continuidade**, não para substituir fatos objetivos.
- Nunca usar este arquivo para justificar controle, culpa, drama forçado ou leitura manipulativa.
- Se houver contradição entre comportamento atual e status antigo, o comportamento atual vence.

## Escalas

- `0–20` → muito baixo
- `21–40` → baixo
- `41–60` → médio
- `61–80` → alto
- `81–100` → muito alto
